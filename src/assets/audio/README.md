# Irish Music for T-Rex Game

## Required File
Place an Irish jig MP3 file named `irish-jig.mp3` in this directory.

## Where to Get Free Irish Music

### Option 1: Free Music Archive (Recommended)
1. Visit: https://freemusicarchive.org/
2. Search: "Irish jig" or "Celtic folk"
3. Filter by: "CC BY" or "Public Domain" license
4. Download an MP3 file
5. Rename it to `irish-jig.mp3`
6. Place it in this folder

### Option 2: YouTube Audio Library
1. Visit: https://studio.youtube.com/channel/UC.../music (requires Google account)
2. Search: "Irish" or "Celtic"
3. Download a track
4. Convert to MP3 if needed
5. Rename to `irish-jig.mp3`

### Option 3: Pixabay
1. Visit: https://pixabay.com/music/
2. Search: "Irish" or "Celtic" or "Folk"
3. Download any track (all are royalty-free)
4. Rename to `irish-jig.mp3`

### Option 4: Incompetech
1. Visit: https://incompetech.com/music/royalty-free/music.html
2. Search genre: "Celtic" or "World"
3. Download (requires attribution in credits)
4. Rename to `irish-jig.mp3`

## Recommended Tracks
- Look for upbeat, traditional Irish jigs or reels
- Recommended tempo: 120-180 BPM (fast and energetic)
- Duration: 1-3 minutes (it will loop automatically)
- File size: Keep under 5MB for faster loading

## Current Setup
The game expects: `src/assets/audio/irish-jig.mp3`

Once you add the file, the music will play automatically when the game starts!
