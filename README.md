# Coirnéal Teicneolaíocht (Technology Corner) 🇮🇪

An Irish language website with interactive alphabet learning app built with Angular and Node.js.

![Angular](https://img.shields.io/badge/Angular-17-red)
![Node.js](https://img.shields.io/badge/Node.js-Backend-green)
![TypeScript](https://img.shields.io/badge/TypeScript-5.2-blue)
![Irish Language](https://img.shields.io/badge/Language-Irish%20(Gaeilge)-orange)

## 🎯 Features

- **📱 Responsive Design** - Works on all devices (mobile, tablet, desktop)
- **🇮🇪 Irish Language Content** - Authentic Irish language navigation and content
- **📚 Interactive Alphabet App** - Learn the Irish alphabet with images and audio
- **📧 Contact Form** - Backend-powered contact form with validation
- **🎨 Modern UI** - Professional Angular architecture with smooth animations
- **🔍 Search Functionality** - Built-in search capabilities

## 🚀 Quick Start

### Prerequisites
- Node.js (v18 or higher)
- npm
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/coirneal-teicneolaiocht.git
   cd coirneal-teicneolaiocht
   ```

2. **Install dependencies**
   ```bash
   npm install
   cd backend && npm install
   ```

3. **Start development servers**
   ```bash
   # Start both frontend and backend
   npm run dev
   
   # Or start them separately:
   npm start              # Frontend (http://localhost:4200)
   cd backend && npm start # Backend (http://localhost:3000)
   ```

4. **Open your browser**
   - Navigate to `http://localhost:4200`
   - Explore the Irish language interface!

## 🎮 Usage

### Navigation (Irish Language)
- **Baile** - Home page with contact form and access to alphabet app
- **Cé muid féin** - About page with family crest and information
- **Eolas** - Contact page with form submission
- **App Gaeilge** - Interactive alphabet learning application

### Alphabet Learning App
- Click letters A-Z to see images and hear pronunciation
- Interactive grid with random colors
- Modal display with close functionality
- Mobile-responsive design
